Why Tesseract?

A tesseract is a four-dimensional cube. The opening diagram projects it onto the screen, and each axis represents a part of the system that handles or observes a controlled run.

X Filesystem
The worker starts with a pinned, read-only Linux filesystem and designated inputs. A separate observer records supported file activity, such as access to the sample document.
Y Execution
Linux namespaces isolate the worker. Seccomp limits which kernel calls it can make, and Linux control groups bound CPU, memory, and process count.
Z Network
A test proxy captures supported HTTP and HTTPS requests. Simulated endpoints let a controlled run exercise network behavior with upstream forwarding disabled.
W Evidence
A separate reader checks the hash-linked event log and reports what was observed, what policy was applied, and where coverage was incomplete.

Capabilities and readiness

Controlled Linux runs exercise the prototype with synthetic inputs. Wider validation takes place before unknown packages can run.

In the controlled prototype

Package and policy checks
Validate package definitions and check content fingerprints against locks in supported scenarios.
Isolation and permissions
Run a workload as a separate worker with a read-only runtime image, explicit mounts, and resource limits.
Behavior observation
Record supported file access and network activity, with coverage tied to the scenario.
Simulated services and synthetic data
Exercise how workloads interact with controlled HTTP, HTTPS, mail, and cloud metadata fixtures.
Evidence checks
Verify the event chain and report observations, missing coverage, and cleanup status.

Product roadmap

Broader agent and component testing
Expand evaluation to full agents, tools, MCP servers, skills, and model artifacts. A disposable virtual machine worker is a gate for unknown packages.
Policy-controlled integrations
Apply explicit rules to approved external services and model requests.
Versioned approvals and updates
Bind signed approvals and test evidence to a release. A changed release returns for evaluation.
Package distribution
Share evaluated releases through catalogs with access controls and approval records.
