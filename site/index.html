Prototype scope

The recorded tests use controlled workloads and synthetic data. Testing unknown third-party packages requires a disposable virtual machine worker. A result applies to the tested workload, inputs, and environment.

A review gate for an internal skill catalog

The first use case is a platform security team deciding which skills employees can install.

A team proposes a new skill. A reviewer inspects the behavior report, checks the requested permissions, and approves a specific version for the catalog. The same review is triggered when that version changes.

Commercial direction. A free local testing tool for developers, with a planned paid self-hosted approval workflow for organizations.

How the test environment works

Filesystem
A pinned, read-only Wolfi filesystem gives the workload its own view of files. The file sensor runs outside the worker's user identity.
Process limits
Seccomp restricts kernel calls. Linux control groups limit CPU, memory, and the number of tasks.
Network
The test proxy captures supported HTTP and HTTPS requests in a simulated service with no upstream forwarding.
Evidence
A separate reader checks the hash-linked event log and reports gaps in observation.
