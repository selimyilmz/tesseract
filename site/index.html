From testing to approval

The report helps a reviewer decide whether and under which permissions a skill should enter an approved catalog.

Before installation In prototype
Run a controlled workload with test data. Record file activity and supported network traffic, including gaps in coverage.
During execution In prototype
Apply the test environment's Linux isolation, resource limits, and network restrictions while the workload runs.
When sharing Planned
Share a specific package version with its approved permissions and test evidence attached.
After an update Planned
Require a new test and approval when the package changes.

Inside the test environment

Each part has a different job, from limiting what the workload can reach to recording what the observers saw.

X Filesystem
A pinned, read-only Wolfi filesystem gives the workload its own view of files. The file sensor runs outside the worker's user identity.
Y Process limits
Seccomp restricts kernel calls. Linux control groups limit CPU, memory, and the number of tasks.
Z Network
The test proxy captures supported HTTP and HTTPS requests in a simulated service with no upstream forwarding.
W Evidence
A separate reader checks the hash-linked event log and reports gaps in observation.

Prototype scope

Validation is in progress with controlled workloads and synthetic data. Broader testing and a disposable virtual machine worker are needed before running unknown third-party packages.

Early HTTPS development run

A controlled run completed with verified cleanup. The simulated endpoint saw two synthetic credential matches. One TLS handshake failed and the report recorded incomplete coverage.

A review gate for an internal skill catalog

The first use case is a platform security team deciding which skills employees can install.

A team proposes a new skill. A reviewer inspects the behavior report, checks the requested permissions, and approves a specific version for the catalog. The same review is triggered when that version changes.

Commercial direction. A free local testing tool for developers, with a planned paid self-hosted approval workflow for organizations.
